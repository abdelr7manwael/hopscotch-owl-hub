Privacy Policy

Hopscotch Owl Hub · Last updated: 30 October 2026

Hopscotch Owl Hub is a private tool used only by the owner of the Hopscotch Owl Books YouTube channel to upload and schedule that channel's own videos. It is not offered to the public and does not access any other person's Google or YouTube account.

1. Google data the tool accesses

PermissionUsed for
Upload YouTube videosUploading the owner's short videos to the owner's channel, with title, description, tags and a scheduled publish time.
View your YouTube accountShowing which channel is logged in before anything is uploaded.

2. How the data is used

  • Only to run the owner's own channel: uploading and scheduling its videos.
  • No data is sold, used for advertising, or shared with anyone else.

3. Where the data is stored

  • Everything is stored only on the owner's personal computer: the login token and the posting plan.
  • There is no server or database run by this tool.
  • Deleting the tool's data folder removes all of it.

4. Removing access

Access can be revoked at any time from Google Account → Third-party apps & services. After that the tool can no longer read or change anything.

5. Google and YouTube policies

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

6. Changes

If this policy changes, the date at the top of this page will be updated.
